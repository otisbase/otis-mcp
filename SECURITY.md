# Security policy

## Report a vulnerability

Email [support@otisbase.com](mailto:support@otisbase.com) with the subject "Security". Do not open a public issue for a security problem.

Include the affected endpoint or tool, the steps to reproduce the problem and the impact you expect.

## Scope

- The hosted service at `mcp.otisbase.com` and `otisbase.com`.
- The code in this repository.

Do not access, change or delete records that are not yours. Test with your own account and fictional data. Do not run denial-of-service tests or send bulk email through the sign-in flow.

## Supported versions

Only the current `main` branch and the hosted service receive security fixes.
